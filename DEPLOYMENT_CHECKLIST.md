## Как пользоваться системой

### Заполнение дневной записи

Когда захочешь записать, что ты ел, напиши Claude:

```
Завтрак: овсянка 200 г, 2 яйца, банан
Обед: куриная грудка 150 г, рис 150 г
Вечер: творог 150 г с орехами
Кофе 2 раза, вода 5 стаканов
Вес утром: 90.5 кг, сон 7 часов
```

Claude:
1. Создаст файл `meals/YYYY-MM-DD.md`
2. Запустит парсер `python scripts/parse_day.py`
3. Пересоберёт дашборд `python scripts/build_dashboard.py`
4. Запушит всё на GitHub `bash scripts/deploy.sh`
5. Скажет результаты (калории, белки, зону, кофе/воду)

### Ежедневный флоу

```
📝 Вечером: "Claude, запиши день..."
↓
⚙️ Claude: парсит, считает, шифрует, пушит
↓
🌐 GitHub: Pages обновляется через 30 сек
↓
📊 Открываешь дашборд, видишь итоги дня
```

## Технические детали

### Безопасность
- ✓ Данные шифруются AES-256-GCM (PBKDF2, 100k итераций)
- ✓ Расшифровка происходит в браузере (WebCrypto API)
- ✓ Пароль `1406` не хранится в коде
- ✓ `.password` файл в `.gitignore`
- ✓ Markdown-записи `meals/` не коммитятся (только зашифрованный JSON)

### Структура данных
- `data/daily.json` — итоги по дням (ккал, КБЖУ, зоны, жидкости)
- `data/weight.json` — история веса по датам
- `data/products.json` — база продуктов (с aliases для мэтчинга)
- `data/config.json` — цели, стоп-лист
- `docs/index.html` — зашифрованный дашборд для публикации

### Python зависимости
```bash
pip install cryptography
```

## Проблемы и решения

### "Дашборд не открывается"
- Проверь что GitHub Pages включен в Settings
- Подожди 60 сек после включения Pages
- Очисть кэш браузера (Ctrl+Shift+Delete)

### "Неверный пароль"
- Пароль должен быть `1406` (без кавычек)
- Если не работает — разморозь дашборд через `python scripts/build_dashboard.py` с правильным паролем

### "Продукт не распознан"
- Парсер напишет в `data/unknown_products.txt`
- Claude автоматически попросит КБЖУ или добавит сам
- После добавления в `data/products.json` — парсер будет работать

### "Git push не работает"
- Проверь авторизацию: `git config --global user.email`
- Если нужно авторизоваться заново — требует GitHub token в браузере
